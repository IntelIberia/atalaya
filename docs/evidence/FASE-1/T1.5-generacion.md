# T1.5 — Generación Python, deriva y round-trip

Fecha: 2026-11-10
Estado: **OK; revisión independiente y puerta global completadas**

## Implementación

`make proto` ejecuta `buf lint` y genera los bindings Python `.py` y `.pyi` con el entorno
congelado. El generador elimina bindings obsoletos solo si `protoc` termina correctamente.
El test de deriva regenera en un directorio temporal y compara rutas y bytes con lo versionado.

La prueba de propiedades recorre los 11 mensajes principales con 200 ejemplos por mensaje:
valida cada mensaje, comprueba `parse(serialize(m)) == m` y exige serialización determinista
estable. Incluye campos anidados, `repeated` y ramas `oneof`.
